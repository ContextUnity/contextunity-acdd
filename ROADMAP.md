# ContextUnity ACDD Roadmap

ContextUnity ACDD evolves around one local-first Rust workspace: precise Tree-sitter code and documentation navigation (`acdd-index`), a domain-agnostic `GateProfile` (`version: 2`) verification state machine (`acdd-state`), and a strict leaf boundary (`acdd-core`) hosting `DomainProvider` extensions. Admitted commitments, task scopes, and dependency edges live in [milestones](docs/milestones/README.md); exploratory studies live in [plans](docs/plans/README.md).

## `v0.7.0` (Current Release Line)

- **Read-Only Live DAG Roadmap (`acdd roadmap` / `acdd_state(action: "roadmap")`)**: Exposes dependency wave planning and active worktree spec overlays via `StateQuery::Roadmap` and `execute_state_query`, suppressing archived divergence noise and gating secondary worktree overlays to active runs.
- **Task Git Checkpoints (`save.post: snapshot`)**: Adds confined per-task snapshot refs under `refs/acdd/snapshots/<run_id>/<task_ref>/r<rev>` (`acdd snapshot save|restore|list|clear` and `acdd_state(action: "snapshot")`) auto-saved on embedded `code` `build` pass and cleaned up on deliver, `clear`, and `handoff`.
- **Roadmap & Dependency Resolution Hot-Path Consolidation ([PF-005](docs/milestones/archive/PF-005-roadmap-and-dep-resolution-hotpath.md))**: Batches multi-blob Git inspections through a single `git cat-file --batch` reader in `crates/acdd-core/src/git.rs`, removes duplicate `git rev-parse` checks in `list_git_tree_entries` and `list_owned_worktrees`, and preloads runs, tombstones, and archive summaries once per `handle_roadmap` / `validate_spec_dependencies` invocation instead of scanning archives per edge across sibling worktrees.

## `v0.7.1` (Next)

- **0-1 Knapsack `ClaimResp` Packing, RRF Search Ranking & SQL External Callers ([UX-003](docs/milestones/UX-003-knapsack-context-rrf-search-and-sql-callers.md))**: Upgrades Tier 6 `ClaimResp` item packing in `src/state_bridge/` and `acdd-state` onto a pure `acdd-core` 0-1 knapsack selector (`pack_knapsack_indices`), replaces hardcoded additive ranking constants in `code_map_search` (`crates/acdd-index/src/db/symbols/search.rs`) with weighted Reciprocal Rank Fusion (`k = 60`) over structural tier, FTS5 BM25, and bounded non-containment graph degree while keeping `exact: true` isolated from `edges`, and extends `code.external_callers` to surface non-test consumers of `.sql` `table` nodes across `defines_table`, `queries_table`, `mutates_table`, and `references_table`.
- **FTS5 Fast-Path Signed-Rowid Fix & Index Pipeline Consolidation ([PF-004](docs/milestones/archive/PF-004-fts-fastpath-codec-safety-and-pipeline-cleanup.md))**: Fixes signed `i64` rowid decoding and eliminates per-document allocations in `fts5_fastpath`, skips no-op delta FTS5 mutations when file projections stay clean, unifies cold/delta SQLite ingest onto `MultiValueBatch`, shares one `PreparedGraph` projection with Rayon-parallel domain hashing and typed RAM staging, consolidates linker flow-interning loops while dropping mid-linker `malloc_trim(0)`, and parallelizes linker prep (`children_by_parent`, `PythonReceivers::build`).
- **Workspace-Wide Modularization, Constant Unification, Typed Contracts & Test Hygiene ([AR-002](docs/milestones/archive/AR-002-modularize-db-reader-and-traversal.md))**: Unifies workspace layout constants, `SubsystemId`, SQLite `MetadataKey`, `MAX_QUERY_RESULT_BYTES`, expanded `NodeDetailKey`, and `models::tags` across all four crates; decomposes god-files (`acdd-core::config`, `acdd-index::{db/reader, db/symbols, db/traversal, semantic, value_flow_phase}`, `acdd-state::{context, usecases/roadmap, usecases/deps, usecases/lifecycle}`, and `src/{cli, mcp/tools, state_bridge/code_domain, engine/pipeline/delta}`) into single-responsibility submodules across 4 disjoint parallel task waves (9 tasks); replaces raw string dispatch and `#[allow(clippy::too_many_arguments)]` with exhaustive boundary enums (`OverviewAspect`, `ExplainDirection`, `ImpactDirection`, `TraversalMode`, `GraphQueryOp`, `SharedOwnerKind`) and typed context structs; eliminates cross-module code clones (`ports.rs`, `SharedRow`, `governing_invariants`, `ExplainOptions`, `db/symbols/search.rs`, `split_python_pipe_types`, `required_configuration_facts`, `machine` active-node guard, `tx.rs::admit_claim`, CLI/MCP/engine helpers) and phantom-tested non-`_with_path` wrappers; bounds `paging::query`, `rows_with_mode`, `directory_boundary`, `dead_tails_paged`, and `duplicates_paged`; and relocates inline `acdd-state` integration test suites (`profile/mod.rs`, `validate.rs`, `context.rs`, `store/sqlite/mod.rs`) into `crates/acdd-state/tests/state_integration/`.
- **Language-Agnostic Architectural & Graph Linter, Executable `INV-*` Rules & Embedded `documentation` Profile ([AR-003](docs/milestones/archive/AR-003-unified-lint-engine-and-documentation-profile.md))**: Extracts fenced `acdd-rule` YAML blocks alongside `INV-*` callouts in Markdown into `Node.details["arch_rules"]` (failing closed via `errors` under existing Merkle commitments); unifies `arch` (`forbid_dependency`, `allow_only_dependencies`, `single_owner`, `forbid_cycles`, `boundary_entry`, `must_implement`, `doc_integrity`, `ast_pattern`), `duplicates`, `dead_tails`, `cycles`, `syntax`, and `docs` behind `crates/acdd-index/src/db/lint/`; exposes dual-surface `acdd lint` CLI, `code_map_lint` MCP, and freshness-verified `code.lint` gate checks (plus `[ENFORCED]` `docs.invariants` badges); adds the 4th embedded `GateProfile` `documentation` (`--profile documentation`); and consolidates scattered `**/AGENTS.md` architectural invariants into canonical `docs/architecture/` and `docs/adr/` pages enforced on ACDD itself.
- **Universal Declarative Language Engine & Tier-1 Coverage ([LS-003](docs/milestones/archive/LS-003-universal-parser-tier1-coverage-and-shell-css-json.md))**: Splits `dependency_registry.rs` into modular typed `ManifestParser` plugins (`Ecosystem`, `ActivationCondition`, `RuleIR`), unifies Tier-2 profiles and default Bash/CSS/JSON + HTML/Jinja2 `.j2` support onto `SyntaxGrammarSpec` + `ValueFlowCollectorCore` + `GENERIC_LINKER`, and expands Tier-1 static resolution coverage across Rust, Python, Proto, and Web/Vue/HTML/JS.

## Next: Agnostic Linker & Lint Overhaul, Idiomatic Cleanup, Swarm Coordination & Repository Memory

- **Language-Agnostic Linker Overhaul, Comprehensive Lint Rules, Cycle Breaking & Modularity Ratchet ([AR-004](docs/milestones/AR-004-agnostic-linker-lint-hygiene-and-modularity-overhaul.md))**: Elevates closure parameter typing (`ValueExpr::CallbackParam`), universal compound generic `.toml` `member_returns`/`call_returns`, tuple `BranchJoin` and monotonic loop-variable typing, struct/tuple/variant destructuring, `lookup_builtin_member`, two-tier polymorphic `Trait`/`Interface` contract edges, and Tier-1 `SyntaxGrammarSpec` adoption across all languages while closing remaining zero-heuristic Rust gaps (`#[derive(Parser)]` `Self`, external re-export aliases, `&dyn Trait` and generic inherent method resolution, `impl` macros); replaces raw 5-line duplicate hashing with Type-2 `src/ast/` AST-statement clone windows, separates `imports` module SCCs from `calls` recursion, enforces `syntax.{fact_budget_exceeded,intra_crate_type_homonym}` (retaining AST complexity telemetry in `node.details`) and `docs.unused_arch_zone` validation, hardens `ast_pattern` with single-parse fail-closed evaluation, breaks the `88`-node `acdd-index` and `5`-node `acdd-core` module SCCs under `forbid_cycles: error`, adds SQLite/linker-backed `unused_public_api` and `acdd serve` executable identity drift protection, strengthens embedded `code` profile architectural-reuse safeguards, and ratchets `check_full_repo` onto all 6 `acdd lint` categories.
- **Typed Graph Core, Full `LanguageLinker` Trait Inversion & Idiomatic Rust Cleanup ([AR-005](docs/milestones/AR-005-typed-graph-core-linker-traits-and-idiomatic-cleanup.md))**: Migrates `Node` and `CompactEdge` onto 1-byte `Copy` enums while eliminating all 288 raw `node.details[key]` JSON accesses (`ARCH-L2-NO-RAW-NODE-DETAILS-INDEX: error`), completes `LanguageLinker` trait inversion (removing `#[allow(private_interfaces)]`, per-language `Context` fields, `__rust_*` string tags, and duplicate Rust path resolvers while wiring Tier-2 OO member indexes), deletes all 14 mechanical context-bag structs (`PreparedVerifyPhase`, `GateCallCtx`, `ChunkPersistSink`, etc.), dual-order DTO shims (`ClassicFieldsFirstDto`), unused root `Cargo.toml` dependencies (`petgraph`, `zstd`, `hashbrown`), and 98 mechanical doc stubs, and introduces typed DB reader DTOs + unified `AcddError`.
- **Unified Swarm Gates & Peer Board Coordination ([AC-005](docs/milestones/AC-005-unified-swarm-gates-and-peer-board-coordination.md))**: Replaces `- tasks:` with one unified `GateDef.mode: linear | parallel | swarm` model, recursive `GateDef.coordinator` groups, `roles:` renamed to `agents:` with explicit worker self-claim, mutually exclusive grouped `save:` variants (including `save: handoff` with `repack: none | linear | by_task | squash`), `GateDef.with` multi-source collection binding (`spec.tasks | blueprint.tasks`, `input.channels`, `poll.items`, `{ count: N }`), extended native `GateDef.when` expressions, lock-free `save: none` SQLite CAS vs. disjoint-scope/worktree isolation for mutating gates, barrier rejection consolidation, and `@mention` + `thread_id` + zero-token `acdd_blackboard` `wait`.
- **Universal Repository Memory Synthesis ([AC-006](docs/milestones/AC-006-universal-repository-memory-synthesis.md))**: Git-tracked `docs/memories/*.md` rules synthesized from execution evidence with staleness/supersession governance, deterministic `ClaimResp` injection across `linear`, `parallel`, and `swarm` nodes, and `acdd_memory` BM25 `query` reuse over `doc_search`.

## Later: Observability & Reactive Automation

- **CLI MCP Split & Read-Only Local Observability ([AC-007](docs/milestones/AC-007-unified-observability-board-otlp-and-metrics.md))**: Explicit `acdd mcp` for session-scoped `stdio` MCP (`install.sh` and adapter updates with safe transition handling) separated from `acdd serve [--webui] [--telemetry]` bound strictly read-only on `127.0.0.1` (`--webui` Live Gate Board UI `GET /`, `GET /api/*`, `GET /events` SSE rendering `AC-005` `linear | parallel | swarm` trees and `@mention` threads; `--telemetry` headless `GET /metrics` bounded-cardinality Prometheus `0.0.4` exposition + incremental OTLP/HTTP JSON trace relay from `traces.jsonl`; default `acdd serve` launches both together with zero inbound state mutations).
- **Zero-Daemon Reactive Core ([AC-008](docs/milestones/AC-008-always-on-reactive-triggers-and-deferred-approvals.md))**: `AgentDef.mode: manual` sleep-at-zero-tokens deferred approvals (resumed via CLI/MCP `approve`/`reject`), `spawner.rs` `env_allowlist` secret scrubbing, claim `lease_expires_at` TTLs, durable SQLite `timers` (`v2 -> v3` migration) and one-shot `acdd tick` pulse (`systemd.timer` / `launchd` / `cron` / CI with `0` idle RAM), durable `inbox` (`dedup_key` + `coalesce_window`) dispatching through `AC-005` concurrent CAS `swarm` execution (`repo.lock` strictly when `save != none`), and paced idempotent `outbox` notifications.

## Future: Authenticated Ingress & Ecosystem Extensions

- **Authenticated Network/IPC Ingress, Interactive Web UI & Streamable HTTP MCP ([AC-009](docs/milestones/AC-009-authenticated-ingress-interactive-webui-and-http-mcp.md))**: Upfront `ADR-0013` Transport & Security layer (`Host`/`Origin` validation, constant-time scoped Bearer tokens, per-source HMAC-SHA256 webhook verification with replay windows, body byte caps, rate limiting), confined `.acdd/acdd.sock` (`0600`, OS-UID auth), `acdd serve --interactive` authenticated Web UI approvals and `@mention` blackboard steering, `acdd serve --incoming` `POST /events` webhook listener, `acdd mcp --http` Streamable HTTP MCP (`POST/GET /mcp` with `Mcp-Session-Id` and token-bound `worker_id` identity), and unified `acdd up` supervisor (`webui`, `telemetry`, `socket`, `incoming`, `mcp_http`, `sleep_until(next_timer)` loop).
- **Thin Ecosystem `DomainProvider` Shim-Crates (`crates/acdd-domain-*`)**: Modular domain crates depending only on `acdd-core` and proven Rust ecosystem libraries (such as OpenAPI diff verifiers, SQL migration linters, and JSON Schema/policy evaluators) plugged into `GateProfile` verification gates without modifying `acdd-state` or `acdd-index`; see the [domain extensions guide](docs/architecture/domain-extensions.md).
